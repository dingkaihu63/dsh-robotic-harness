# 安全边界（Safety Boundary）

> 本文件是 RH 的“非承诺”清单：哪些事 RH 明确不做，为什么，以及使用者必须知道的风险。

## 1. RH 不是功能安全系统

- RH 是**研发监督与诊断工具**，未经任何功能安全认证（IEC 61508 / ISO 10218 / ISO/TS 15066 等）。
- 任何“仿真通过”都不构成真机安全声明。仿真结果只是风险证据之一。
- 不要用 RH（或任何 LLM 工作流）替代急停、安全门、限位等设备侧安全机制。

## 2. 当前版本没有真机能力

- 本仓库 v0.1 **不包含**任何真机硬件适配器、真机写工具或任意 Topic 发布工具。
- 即便未来接入真机，也遵循以下约束（设计不变式）：
  - DSH/LLM 无权解除急停、绕过安全门、修改硬件限位或清除未知硬件故障；
  - 所有控制类调用必须经过 allowlist、参数 schema、机器人状态检查和人工审批；
  - 高频闭环（PID/MPC/阻抗）永远运行在控制器/实时系统内，RH 只下发受约束目标并监控状态；
  - Edge/ROS 2 侧负责 watchdog 与失联停机。

## 3. 权限分级（设计约定）

| 级别 | 含义 | 本仓库现状 |
|---|---|---|
| R0 | 纯读取（检查/审计/诊断） | ✅ 已实现 |
| R1 | 本地派生（转换/生成报告/证据导出） | ✅ 已实现 |
| R2 | 启动仿真（MuJoCo） | ✅ 已实现（仅本地、无网络操作） |
| R3 | 受控真机动作 | ❌ 未实现；未来必须 physical approval + preflight + 状态版本绑定 |
| R4 | 禁止通用 Agent 执行（急停解除等） | ❌ 永不以普通 Tool 暴露 |

## 4. Demo 内的已知简化（必须披露）

- **运动学吸盘**：吸附后物体位姿由代码覆写跟随吸盘，不模拟真实吸力/接触力学；已在 run 配置（simNotes）与报告中标注。
- **模拟感知**：渲染器不可用时，感知退化为“真值 + 噪声 + 偏移故障”，遥测记录 `renderer: simulated`。
- **确定性物理**：MuJoCo 默认积分器 + 固定 seed；同一机器的结果可复现，跨平台/版本结果可能不同。

## 5. 数据与人

- 本仓库不收集、不上传任何遥测或日志；worker 全部本地执行。
- 计划中的人类数据模块（人体姿态/生理信号）必须遵循当地法律与机构伦理要求：知情同意、参与者 ID 分离、默认本地处理、导出前敏感字段审计、不提供医疗结论。

## 6. 供应链与信任

- `rh-tools.pythonPath` 是**受信配置**：worker 以该解释器执行随包代码。安装来源不明的 bundle 或修改 pythonPath 等于信任任意代码执行。
- 从 git 安装 bundle 时，pnpm 会要求显式授权 `prepare` 脚本 —— 只对源码可信的包授权，并锁定 commit。
- 若未来接入 MCP Server，其输出仍须经过 RH Tool Policy，不信任第三方服务器。

## 6.5 远程训练（training 模块）的安全不变式

- **服务器必须显式配置**：`<storeRoot>/train-servers.json` 里的 `{"servers": [{"id","host","user","keyPath?","port?","workDir?"}]}` 是唯一信任来源；未配置时工具返回 `backend:"unavailable"`，绝不猜测主机。
- **默认只准备，不执行**：`train-job-prepare` 默认 dry-run，只在本地生成 `train.py` / `launcher.sh` / 计划快照。远程提交要求**同一次调用**同时满足 `dryRun:false` 与 `confirm:true`，且服务器可达。
- **命令白名单化**：远程只执行本工具生成的启动器（在配置的 workDir 内），只上传本工具生成的产物；不存在自由形式的远程命令执行。
- **脚本是模板占位**：生成的训练脚本是确定性的占位模板，不是真实模型训练代码；Agent 必须如实说明，不得暗示"正在训练真实模型"。
- **文献/数据集是证据不是结论**：`literature-search` 的结果带来源 URL，可能来自尽力而为的网络调用（失败时如实返回 unavailable）；`train-data-discovery` 命中的数据集未经人工校验，使用前必须检查许可与质量。
- **报告不是发布依据**：`train-report` 只做日志统计（收敛判断），发布模型需要验证集与真实场景评估。

## 7. 报告义务

自动生成的报告/诊断必须：

- 区分事实、规则判定与推断（视觉与措辞均不可混同）；
- 每个结论可追溯到 Artifact（遥测行、图表、配置快照）；
- 明确缺失证据与建议的只读验证步骤；
- 不把“仿真通过”写成“真机安全”。
