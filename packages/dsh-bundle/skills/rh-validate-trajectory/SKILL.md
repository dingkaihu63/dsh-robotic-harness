# 执行前轨迹校验

固定检查顺序，先静态后对比，仿真校验不等于真机安全。

1. **校验轨迹。** `rh_trajectory_validate` 检查：位置/速度/加速度连续性、关节限位越界、速度与加速度上限、时间戳单调性。逐项给出通过/失败与越界数值。
2. **对比已执行轨迹。** `rh_planned_actual_compare` 将计划轨迹与同类任务已执行的实际轨迹对比（如有）：偏差、跟踪误差模式、越界历史。
3. **汇总报告。** 输出轨迹问题清单（error/warning）、越界位置与时刻，以及"通过校验"结论。结论措辞限定为"静态校验通过"，不得延伸为"真机安全"。

## 成功判据

- 连续性、限位、速度三类检查全部有结论。
- 对比步骤若有可用实际轨迹则完成，无可用的则明确说明未对比。

## 停止条件

- 轨迹文件缺失或时间戳不单调：停止并报告，不修改轨迹后"修复通过"。
- 存在限位越界 error：停止前必须高亮该段，交由用户决定是否重规划。

## 常见误判

- **仿真/静态校验通过 ≠ 真机安全**：摩擦、间隙、通信时延、急停距离不在校验范围内。
- 连续性检查只看数值平滑，不代表动力学可行（如加速度突变仍在限内但冲击过大）。
