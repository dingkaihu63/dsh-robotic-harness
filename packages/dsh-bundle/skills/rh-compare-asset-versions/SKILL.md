# 资产版本对比

固定检查顺序，先量化差异，再评估影响。

1. **确认可解析。** 分别用 `rh_robot_asset_inspect` 检查两个版本的资产都能正常解析，记录各自的 issue 计数（若任一方无法解析，对比无从谈起）。
2. **对比版本。** `rh_cad_compare_versions` 对比两个 URDF 或 CAD 清单（路径由用户提供，确认基线与目标版本）。记录对比模式与哈希。
3. **列出变化。** 逐项列出差异：新增/删除/重命名的 link 与 joint、mass 变化、inertia 变化、几何/网格变化、joint limit 变化。给出数值与相对百分比。
4. **评估影响。** 判断每类变化是否影响仿真（动力学数值）或规划（运动学链、限位、可达性）。影响判断标注为推测，并给出依据。
5. **输出报告。** 汇总差异表与影响评估，指出需要人工确认的项（如命名改变导致的引用断裂）。

## 成功判据

- 差异清单覆盖 link/joint/mass/inertia/limit 全部类别；每个"影响仿真/规划"的判断都附有数值依据。

## 停止条件

- 任一版本路径不存在或无法解析：停止并确认路径；两版本结构差异过大（如拓扑完全不同）时改为建议人工评审。

## 常见误判

- **质量变化 <10% 不应夸大**：在多数抓取/规划任务里属可忽略级别，除非涉及高动态（如抛掷、碰撞补偿）。
- 文件修改时间不同 ≠ 内容有语义差异；以哈希与解析结果为准，不以时间戳下结论。
