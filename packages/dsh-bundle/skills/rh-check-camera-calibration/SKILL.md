# 相机与标定检查

固定检查顺序，先图像后标定文件，再数值验证。

1. **健康检查。** `rh_camera_health_check` 检查图像质量：过曝/欠曝、模糊、坏点、遮挡。图像本身不可用则标定检查无意义，先解决图像问题。
2. **检查标定文件。** `rh_calibration_inspect` 检查标定文件结构：内参矩阵、畸变系数、图像尺寸、相机型号与时间戳。记录文件完整性。
3. **评估重投影误差。** 从标定文件/样本数据中读取重投影误差：**误差 >1px 时建议重新标定**；>0.5px 时提示复核。误差数据缺失时如实说明"无法评估"。
4. **校验外参。** `rh_pose_transform_validate` 校验相机到机器人基座/工具的外参变换：数值一致性、旋转矩阵正交性、平移量级合理性。
5. **输出报告。** 汇总健康/标定/外参结论，区分"文件存在"与"标定正确"，给出是否重标的建议。

## 成功判据

- 四步全部执行，报告区分文件结构状态与数值正确性；重投影误差有明确阈值判断或明确标注"无法评估"。

## 停止条件

- 相机不可达或图像全黑/全白：停止并报告硬件/连接问题；标定文件与相机型号/分辨率不匹配时提示重新标定。

## 常见误判

- **不能仅凭文件结构声称"标定正确"**：文件完整只说明格式合规，数值正确性必须靠重投影误差/外参验证。
- 内参来自旧相机≠当前相机：核对型号与序列号后再采信。
