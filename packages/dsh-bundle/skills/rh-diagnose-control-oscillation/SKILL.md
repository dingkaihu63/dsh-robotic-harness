# 控制振荡诊断

固定检查顺序：**先查频率与时间戳，再谈 PID 参数**。

1. **检测振荡。** `rh_control_trace_analyze` 确认振荡存在：频率、幅度、是否持续。记录振荡的起止时间与大致频率。
2. **核对频率与时间戳。** `rh_telemetry_channels` 列出通道，核对振荡频率与传感器采样率/控制周期/传输时延的关系（如 2× 控制频率处的振荡多指向离散化问题，低频振荡多指向机械/摩擦）。检查时间戳是否对齐、有无丢帧。
3. **对比参数。** `rh_controller_config_compare` 对比当前控制器参数与基线/出厂参数：增益、积分限幅、滤波。列出差异并标注"哪些参数变化与振荡同时发生"。
4. **可选辨识。** 如证据不足，`rh_system_identification_job` 做一阶/二阶辨识，估计对象增益与时间常数，验证"增益过高"假设。
5. **分层报告假设。** 按 控制层（增益/相位裕度）/ 机械层（摩擦、谐振、间隙）/ 系统层（采样、时延、数据质量问题） 三层列出假设，每个假设附证据支持度，并明确标注"未确认"。

## 成功判据

- 报告包含振荡频率、时间戳核对结果与参数对比；假设按三层归类且全部标注未确认，无"确诊"式措辞。

## 停止条件

- 数据无法定位振荡（无振荡或数据残缺）：停止并说明，不强行调参建议；未先核对频率/时间戳就得出 PID 结论时视为违规，回退重做。

## 常见误判

- 把所有振荡都归因于 PID 增益——先排除采样/时延/数据质量问题。
- 把一次辨识结果当确定性模型：辨识结果同样是假设，需交叉验证。
