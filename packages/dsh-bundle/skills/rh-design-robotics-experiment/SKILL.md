# 机器人实验设计

固定检查顺序，先定义后执行，规格不完整不启动。

1. **创建实验规格。** `rh_experiment_spec_create` 定义：研究问题、假设（可证伪）、指标、自变量/控制变量、随机种子、重复次数。规格必须完整，`openQuestions` 里留白的问题**先补齐再继续**。
2. **展开矩阵。** `rh_experiment_matrix_expand` 把规格展开为参数矩阵，确认单元数量与资源预算匹配。
3. **执行基准。** `rh_benchmark_start` 运行矩阵。记录每单元的成功/失败与产物路径。
4. **计算指标。** `rh_metrics_compute` 聚合指标：均值/方差/置信区间。样本不足时标注不确定性。
5. **对比消融。** `rh_ablation_compare` 对比消融条件，区分"显著差异"与"噪声波动"。
6. **生成报告。** `rh_benchmark_report` 输出实验报告：结论必须限定在数据支撑范围内，明确未验证的假设。

## 成功判据

- 规格含研究问题/假设/指标/变量/种子/重复六要素，且 openQuestions 已补齐；矩阵执行完成，指标与消融对比有数据支撑。

## 停止条件

- 规格缺假设或指标：停止并补齐，不允许无假设实验；矩阵过大超出资源时停止并与用户协商缩减，不静默裁剪条件。

## 常见误判

- 消融对比的差异若无置信区间支撑不当作结论；重复次数不足（如每种条件 3 次）时报告必须声明统计效力有限。
