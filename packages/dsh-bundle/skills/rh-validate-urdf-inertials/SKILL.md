# URDF 惯量专项校验

固定检查顺序，先结构后数值，逐步留证。

1. **整体校验。** `rh_urdf_validate` 检查 URDF 结构与引用完整性，记录基线 issue。
2. **惯量专项。** `rh_inertia_validate` 逐 link 检查惯量矩阵：对称性、正定性、非负对角元。惯量矩阵必须正定——非正定意味着物理上不可能，直接标 error。
3. **单位检查。** 核对单位一致性：长度 mm/m、质量 g/kg、角度 deg/rad 不得混用（典型错误：把 mm 尺寸配 g 质量、把 deg 当 rad 写入 joint limit）。列出不一致处及换算后的期望值。
4. **汇总报告。** 输出每个 link 的惯量状态（ok/warning/error）、单位问题清单，以及最可能影响动力学仿真的一条结论。结论标注为推测时明确说明。

## 成功判据

- 每个 link 的惯量都有明确判定，单位检查覆盖所有数值字段；报告包含正定性结论与单位问题清单。

## 停止条件

- 文件不存在或无法解析：停止并报告，不猜测数值。
- 惯量缺失且该 link 是运动部件：停止前必须标为 error 并请用户补充，不得用默认值掩盖。

## 常见误判

- **零惯量 ≠ 错误**：固定件或与父件刚性连接的 link 零惯量可接受；只有运动 link 的零惯量才是问题。
- 单位错误常被误读为"数值偏大/偏小"——先做单位换算再评价量级。
